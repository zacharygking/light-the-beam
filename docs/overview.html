What it does

Features

Next game, always up

Opponent logo, home or away, tipoff in Pacific time, and a countdown. Pulled from ESPN's public schedule; no account or API key.

Live score and clock

Score, quarter and game clock refresh every 20 seconds during the game. The leader is drawn in white; the trailer fades to grey. Scores animate when they change.

The beam lights itself on a win

When the final goes Kings, purple climbs the tube from the base, like the real one, then holds. It goes dark again before the next game.

Light it yourself

Tap the screen to turn the beam on or off any time. Hold for a second to cycle brightness through three levels.

Sleeps at night

The screen dims between 11 pm and 7 am, and whenever the board's light sensor sees a dark room.

Phone WiFi setup

First boot puts up a "KingsBeam-Setup" network. Join it from a phone, pick your home WiFi, done. Nothing is typed into code.

One cable, no soldering

A single USB charger powers the board and the beam. Three lever nuts join the strip to the board's pigtails.

Stock arena, new plinth

Dave Lack's Printables arena prints unmodified. A new printed plinth underneath holds the board, the screen window and the cable exit.

Things learned building it

ESPN's edge rejects browser-style user agents from non-browser clients with a 403, but accepts the ESP32 library's own default. The firmware never spoofs a browser.

The JSON nests fourteen levels deep. ArduinoJson's default limit is ten; the parser raises it and checks for the team object, since a filtered parse reports success on an HTML error page.

Fonts are converted from TTF to LVGL's bitmap format with a small Python script, so the build needs no Node toolchain.
